# VR Assistant 2.0.1

- Live/Test selector now shows the latest reported branch version and switching back to Live is repaired.
- Game Updates is reduced to a single UPDATE GAME workflow.
- Official launcher is closed automatically after the selected branch reaches its target version.
- Footer typography/readability improved.
- Advanced Switch Bindings Add flow auto-detects the first switch transition after opening and ignores held inputs.
- New 2-state switches default to pulsing the same virtual button on ON and OFF transitions, matching War Thunder single-toggle commands such as landing gear.
- Advanced Switch UI and VTrim typography enlarged to reduce overlap/clipping.
- Navigation text enlarged and bolded.
