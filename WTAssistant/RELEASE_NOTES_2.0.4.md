# VR Assistant 2.0.4

## Home / branding
- Replaced the Home hero artwork with the supplied transparent WT VR Assistant image.
- Rebuilt the executable icon from the same supplied artwork at multiple Windows icon sizes.
- Moved the Live/Test selector to the top of the action column.
- Enlarged Monitor and VR cards, their icons, and the Launch Game control.
- Reworked the Monitor, VR headset, Live-server and Test-server vector icons.
- Enlarged and centered server labels/version text inside the server cards.
- Anchored Neck Assistant, KeyBind Assistant, VTrim Assistant, Discord, YouTube and Buy Me a Beer near the bottom.
- Removed duplicate `VR ASSISTANT / FOR WAR THUNDER` text from the left navigation.

## Neck Assistant
- Increased Simple/Advanced binding/help areas so explanatory text is not clipped.
- Added host-size-aware typography scaling for the illustrated interface.
- Corrected a narrow-layout ordering issue in the Advanced binding section.

## KeyBind Assistant / Custom Switch Builder
- Rebalanced State / Conditions / Virtual / When to Act / Output Behavior columns.
- Increased combo drop-down width so `Pulse same command (toggle)` remains fully readable.
- Added an `EXAMPLES` window with practical two-state, held-output and three-state scenarios.
- Added a compact responsive header arrangement for narrower windows.

## VTrim Assistant
- Reflowed Trim Bindings into five clear command bands and fixed the Rudder section being placed outside its table row count.
- Added more room for Rudder/Yaw assist controls, Trim Precision labels, hold-speed controls and device status text.
- Setup/Dashboard pages scroll instead of crushing fixed-height controls when the host is short.
- Added profile Aircraft Type: `Prop Plane`, `Jet Plane`, or `Helicopter`, including owner-drawn category icons.
- Aircraft Type is persisted with each VTrim profile for future category-specific functionality.

## Game update dialog
- Increased version/status typography.
- Increased Update Game button height and moved it to the bottom of the dialog.
