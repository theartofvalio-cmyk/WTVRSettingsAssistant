# War Thunder VR Assistant v2.0.5

This update restores the VTrim profile navigation and improves the Home aircraft strip.

- Double-clicking **VTrim Assistant** expands its **Profiles** submenu again. The Home footer remains clear of the misplaced Profiles search and star controls.
- The Home aircraft strip shows three cards at normal desktop window sizes, including Windows display scaling at 125% and 150%.
- When War Thunder selects an aircraft profile, its Home card is highlighted and automatically scrolled into view so it can be opened for editing.

The update preserves local profiles and settings. The ZIP and executable both identify this release as **v2.0.5**.
