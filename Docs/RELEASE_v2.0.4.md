# War Thunder VR Assistant v2.0.4

This update repairs aircraft profiles created from raw War Thunder telemetry names and improves automatic updates.

- Existing profiles such as `ah_64e`, `av_8b_plus`, and `f_84f` are matched to the aircraft catalog, given the correct aircraft ID, and shown with the proper aircraft name. User-created profile names and control settings are preserved.
- A packaged aircraft catalog is available immediately on first launch, even if the Wiki is slow or temporarily unavailable. The app continues to refresh the catalog online for newly added aircraft.
- Missing or damaged aircraft artwork is restored to each user's local cache. Artwork for the reported AH-64E, AV-8B Plus, and F-84F is included with the app so those profiles display correctly without waiting for a download.
- Removed the duplicate Profiles entry, the misplaced Home footer Profiles control, and the Update App button. Automatic update checks remain active.
- Automatic updates now show a progress window while downloading, verifying, and installing, followed by an automatic restart.

The updater keeps local profiles and settings. The ZIP and executable both identify this release as **v2.0.4**.
