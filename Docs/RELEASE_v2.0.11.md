# War Thunder VR Assistant v2.0.11

- **Simple mode:** added **Unlock rotation speed up to 300%** below Camera Transition Speed. Enable it to extend the slider from 100% to 300%. It is off by default.
- **Advanced mode:** enter an exact rotation speed from **1% to 300%** in the numeric field beside Camera Transition Speed. The slider stays synchronized; no extra checkbox is shown in Advanced mode.
- Values above 100% increase the actual rotation rate and shorten the transition response. At 300%, the angular-rate limits are three times those at 100%, with smooth acceleration and settling retained. The 1–100% response is unchanged.
- Speed and unlock settings are saved and shared between modes. Turning the Simple-mode unlock off caps the selected speed at 100% immediately.
- Added translations for all supported languages and adjusted spacing for longer translated text.

The updater preserves local settings and profiles. For a manual install, extract the entire ZIP and keep the executable, DLLs, Drivers and Licenses together. The ZIP contains no personal settings or profiles.

Automated checks cover speed limits, saved settings, motion response, mode switching and localized layouts. Actual headset feel still requires a VR hardware test.
