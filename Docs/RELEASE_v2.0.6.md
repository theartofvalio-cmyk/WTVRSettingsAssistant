# War Thunder VR Assistant v2.0.6

This release adds the locally tested 2.0.6 controls and Home changes while retaining the aircraft profile and updater fixes from v2.0.2 through v2.0.5.

- Configure Hover UP and Hover Down bindings to hold Left Shift and Left Ctrl while the assigned input is pressed.
- Assign Score Board Mouse Fix to the game's scoreboard button to move the pointer to the top-left of its screen.
- Show up to three centered aircraft cards on Home at normal and full-screen sizes. The compact strip has no footer search or favorite controls. The active aircraft remains highlighted and is scrolled into view.
- Show RUNNING in muted beige on the grey launch button while War Thunder is running.
- Show notes for this release only on the Info page, in each supported language.

The update preserves existing settings and aircraft profiles. Extract the whole release ZIP when installing manually. The ZIP and executable identify this release as **v2.0.6**.
