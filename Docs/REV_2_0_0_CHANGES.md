# Revision 2.0.1 changes

This revision is the v2.0 UI/input-mapping milestone.

- Removed server online/offline presentation from the Home selector; Live/Test are selections only.
- Converted Home assistant feature cards to icon + ON/OFF only with hover tooltips.
- Increased and bolded sidebar navigation text.
- Neck Assistant always enters Simple mode on application launch, omits old Home/Info overlays, and places Camera Transition directly under Simple Hold.
- Added Advanced Switch Bindings under KeyBind Assistant with persistent custom maintained-switch definitions, learning, testing, debounce, startup handling, state transitions and modular output abstraction.
- VTrim continues to use vJoy and receives larger embedded typography plus aviation-style panel framing.
- Bottom-right application label is `v 2.0`.
